# Tasteful Web Design — original repository skill

This is a lightweight original workflow, not a copy of the third-party Taste Skill.

1. Identify the audience, content, primary action, brand personality, and any reference design.
2. Define design tokens before building: type scale, spacing scale, max-width, colors, radii, shadows, and interaction states.
3. Establish one clear visual hierarchy. Give content breathing room and align elements to a consistent grid.
4. Avoid generic AI-looking designs and excessive gradients, emojis, decoration, and fake testimonials.
5. Create a coherent mobile layout first, then refine tablet and desktop.
6. Check contrast, readable text sizes, RTL/Hebrew typography when needed, and accessible focus indicators.
7. Reassess visually after implementation, fix inconsistencies, then run browser-quality checks.
