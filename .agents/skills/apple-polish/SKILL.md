# Apple-inspired UI Polish — original repository skill

This is an original compact checklist; it is not Emil Kowalski's full apple-design skill.

1. Simplify interactions and remove unnecessary visual noise.
2. Use precise spacing, clear typography, natural affordances, and consistent corner radii.
3. Implement hover, focus, disabled, loading, error, success and empty states where applicable.
4. Make motion purposeful, subtle, and skippable; respect `prefers-reduced-motion`.
5. Ensure tap targets are comfortable and buttons respond clearly on touchscreens.
6. Do not imitate brand marks, copy copyrighted interfaces, or claim compliance without testing.
7. Evaluate the experience with real keyboard and mobile browser checks.
